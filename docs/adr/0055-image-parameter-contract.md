# 图片参数声明与生成合同

图片协议通过 provider contribution 的 `imageParameters` 声明字段名称、标签、类型、支持值或范围、默认值、适用模型、计价资格和请求绑定。渠道只可启停字段或收窄插件范围，服务器重新读取插件定义验证，不信任客户端提交的绑定。

可选 `userVisible` 控制 C 端展示，省略时显示。管理员可以覆盖展示设置，隐藏字段仍保留默认值、验证和请求绑定；`enabled=false` 才禁用参数。后台能力编辑始终保留完整配置。多个线路合并时，只要任一路线展示该参数，合并前台合同仍可展示；全部隐藏才隐藏。使用既有能力 JSON 保存，无数据库迁移。

分辨率（imageResolution）、质量（quality）、比例或尺寸（size）是独立语义。管理表单、价格条件、前台模型、创作页、画布与 Agent 审批读取同一合同。pricing=false 的参数仍参与生成，价格表单仅显示 pricing=true 且启用的字段。枚举用平铺选项，数值、布尔和文本使用对应控件。

分辨率关闭时比例配置显示一组，开启时按管理员当前填写的档位显示。size.defaultTier 指定关闭分辨率后的有效像素组；存储保留其他组，重新开启时恢复。多个像素组缺少明确默认组时拒绝保存与执行。纯比例协议不需要像素换算。像素协议只使用已声明预设，不根据模型名猜测输出尺寸。

新配置或新增组默认选择 1:1、4:3、3:4、16:9、9:16、21:9，并受插件支持范围限制；已保存的选择和精确像素保持。capabilityOptions 保存公开意图，config.size 保存实际请求编码，扩展字段不能覆盖已经转换的像素值。

本次使用已有 JSON 列，没有数据库迁移。未声明 imageParameters 的插件保持既有处理路径。升级插件时需同时更新源码 manifest、嵌入说明和安装包。

验收覆盖仅分辨率、独立分辨率与质量、MJ 非计价扩展、字段关闭与重开、保存重读、精确像素、false/0、非法绑定、越界参数和定价一致性。真实供应商生成与费用需由维护者在自己的渠道单独验证。
