# 精灵宠物

在“站点及外观 → 画布配置 → Agent 形象”导入宠物，预览就绪后选择“精灵宠物”，点击页面顶部“保存修改”。角色不内置在程序中，不限定画风。现有动态球与 Live2D 仍可独立选择。

## 导入方式

- Codex v1/v2：上传包含 `pet.json` 和其引用图片的 ZIP，自动识别 192×208 单帧、标准动作和 v2 的 16 向注视。
- 自定义图集：直接选择 PNG / 静态 WebP 图片，导入后设置单帧宽高、动作行列和帧数。图片初始作为一张静态帧，不猜测排列。
- 自定义包：ZIP 包内 `pet.json` 使用 `yinghui` 对象声明下面的配置；可附带 `.txt` / `.md` 授权文件。

ZIP 最大 16 MiB，最多 16 个条目，解压累计 24 MiB。直接导入图片最大 15 MiB。图片最大 4096×4096、最多 64 行/列，单帧至少 8px。只读取包内图片，不运行脚本或加载包提供的远程 URL。素材会发送到浏览器，请确认公开使用授权。

## 编辑动作

每个动作有唯一标识、显示名、行、起始列、帧数、帧率和循环开关。行、列和中立帧序号从 0 开始，动作在同一行内顺序播放，最多 48 个动作。图片尺寸由服务端确认；更换图片需要重新导入。

状态映射包括待机、工作、等待审批/回答、失败、完成、左右拖动、悬停互动、问候、睡觉和醒来。待机必须绑定；其他动作可关闭并使用待机。没有睡眠图片时不应把普通帧标成完整睡眠动画。

空闲自动睡眠默认关闭。绑定睡眠动作后可设为 60–3600 秒；键鼠活动会唤醒，运行任务、清理和待处理审批会阻止入睡。睡眠只改变形象，不会暂停 Agent 或更改权限。

动作优先表达真实业务状态，再处理拖拽与互动。完成只在当前任务确实转为完成且清理结束时短暂播放；加载历史记录或 SSE 重连不重复庆祝。停止、拒绝回到待机；断线保留最后可信任务状态。失败动作播放后可定格，错误详情仍由原有界面提供。

悬浮入口支持拖动、键盘移动和位置保存。对话面板标题栏保持无头像布局；欢迎区域使用系统默认宠物的中立帧。后台“试播动作”不会启动真实任务。

## 用户选择与大小

右键宠物打开四瓣菜单：换形象、调大小、锁位置、暂时收起。点击形象缩略图后切换；超过五个选项时可打开完整列表。大小使用 50%–150% 的滑块，步长 5%，100% 为该形象的系统默认大小。滑动实时预览，松手保存。锁位置只阻止拖动和方向键移动，不影响打开对话。暂时收起后保留“显示宠物”和对话入口。

手机长按 500ms 打开底部面板；移动达到拖动阈值时取消长按并执行拖动，避免同时打开菜单。键盘可用菜单键或 Shift+F10 打开、Esc 关闭；Agent 设置也提供“宠物外观”入口。

个人设置仅影响画布悬浮宠物，不改变首页、对话标题、助手身份、任务权限或其他账号。登录用户按账号跨设备保存，游客按浏览器保存，游客设置不转入登录账号。保存失败显示本机暂存和重试入口；版本检查防止旧页面静默覆盖其他页面。系统减少动态效果变化会立即反映到悬浮宠物。

后台形象库支持添加、命名、发布、排序和选择系统默认。默认项必须已发布；未发布的形象不对普通用户提供资源。后台默认大小为 120–360px 滑块，保留统一保存/撤销流程。动作细节在“高级动作设置”展开。旧版当前形象自动作为默认项进入形象库，并保留动态球选项。

## 自定义配置示例

将以下 `pet.json` 与一张 256×128、每格 64×64 的 `atlas.png` 一起打包。图集第一行四帧待机、第二行四帧睡眠。实际图片必须与配置一致。

```json
{
  "displayName": "我的角色",
  "spritesheetPath": "atlas.png",
  "yinghui": {
    "displayName": "我的角色",
    "atlasWidth": 256,
    "atlasHeight": 128,
    "frameWidth": 64,
    "frameHeight": 64,
    "neutralFrame": 0,
    "lookStartFrame": -1,
    "lookDirections": 0,
    "speed": 1,
    "sleepAfterSeconds": 300,
    "author": "",
    "source": "",
    "license": "",
    "actions": [
      {"id":"idle","label":"待机","row":0,"start":0,"frames":4,"fps":4,"loop":true},
      {"id":"sleep","label":"睡觉","row":1,"start":0,"frames":4,"fps":3,"loop":true}
    ],
    "bindings": {"idle":"idle","sleep":"sleep"}
  }
}
```

可导出后台调整后的 `pet.json`，与原图片一起重新打包复用。导出不包含图片或授权转让。增加睡觉、跳跃等动作时，先制作对应帧，再扩展图集、重新导入和绑定。

减少动态效果模式使用中立帧，任务文字和审批标识继续工作。角色隐藏、离开视口或浏览器后台时暂停播放。原始单帧尺寸决定清晰度，放大显示不会补出新细节。

未发布且未入库的包只能由上传管理员预览；形象库引用的包可由其他管理员维护。当前启用形象和已发布形象通过专用公开接口读取；下架后用户回到系统默认。草稿和已发布条目的资源都受引用删除保护；先移除引用并保存，再清理资源。
