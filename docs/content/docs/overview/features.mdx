## 用户分组与多币种计价

管理员在后台「用户与运营 → 用户分组」维护分组（例如 default / vip / svip）：设置分组倍率（1 为不打折，0.8 为 8 折）、「1 USD / 1 CNY = N 积分」兑换比例、可用的系统渠道（或开放全部渠道），以及单个模型的倍率和兑换比例。再在「用户管理」的编辑抽屉里给用户分配分组，列表可按分组筛选。用户只能看到并使用所属分组绑定渠道下的模型，价格按分组换算后展示和扣费；管理员账号可见全部渠道。分组可选 VIP 或 SVIP 徽章：VIP 为香槟金箔铭牌配金属头像框，SVIP 为黑曜石铭牌配紫粉极光描边，流光定期扫过、头像框缓慢流转（开启「减少动态效果」时静止）。用户端顶栏头像、侧栏和账户卡片展示徽章与头像框，后台分组编辑抽屉可同时预览两者。

渠道模型的「积分定价」页可选择计价货币：积分、USD 或 CNY。货币计价时售价按货币填写，扣费时按用户分组的兑换比例换算成积分。「支付充值 → 充值商品」可选择默认充值货币（CNY / USD），每个商品也可单独设定售价货币。接口与数据结构见 [HTTP API 合同](/docs/backend/http-api) 和[后端数据库](/docs/backend/backend-database)。

## 短剧精修画布

短剧自动制作是事实源，关联的画布是精修台。每部短剧有一张精修画布：制作台顶栏「精修画布」、本集「在画布中打开本集」、设定详情与剧情段弹窗里的「在画布中精修」、成片页「到画布精剪」都会打开它（没有时自动新建并关联），并把对应对象投送过去。画布左侧的短剧侧栏列出设定与分集，可以按设定、单个剧情段、整集或成片投送，已投送的对象点击即定位；底部显示已用积分（含画布精修）与预算。

- 投送：设定是一张带外观描述的图片节点，历史参考图作为节点版本；剧情段是一个段框，内有短剧提示词参考副本、按“参考图N”顺序连到视频的参考图、首帧（上一段尾帧）、带完整提示词的视频节点与本段镜头表，可直接在画布上换首尾帧、延长或重新生成；成片是视频节点，「剪辑」把各段视频按成片顺序载入画布时间线精剪。投送的媒体由服务端登记为素材（我的素材里能看到），不复制文件。
- 采用：图片或视频节点的工具栏与右键菜单提供「采用到短剧」，写成短剧的一个新版本。设定参考图采用后锁定，可选让引用它的剧情段重新生成（画布里默认不勾选）；剧情段视频默认只换本段，也可让后续已生成的段以新视频尾帧重新生成。采用前提示画幅、音轨、时长差异与本段是否正在生成；段刚被修改时拒绝并要求刷新。
- 过期提示：短剧侧有更新的版本（流水线重新生成、制作台上传或其他画布采用）时，画布节点显示「短剧已更新」，点击或用工具栏「同步短剧」换成最新版本，画布上的画面保留在版本历史里。
- 版本记录：制作台的设定与剧情段显示版本记录，标出来源（生成、上传、来自画布）与当前版本。
- 预算：画布上生成任务的花费计入短剧预算与已用积分，预算用完后精修画布也不能再提交生成。
- 反向：画布分镜脚本节点右键「交给短剧自动制作」，按分镜原样转录为新短剧；未关联项目的画布在创建后成为它的精修画布。
- Agent：关联短剧的画布上，Agent 多出读取短剧上下文与「采用到短剧」两个工具，采用总要审批。

接口见 [HTTP API 合同](/docs/backend/http-api)。

## 短剧并行出片与 WAN 3.0 拼车中转

短剧制作设置与新建页新增「段落衔接」：

- 尾帧续接（默认，原有行为）：第 2 段起用上一段视频最后一帧做首帧，同一集按顺序逐段生成。
- 并行出片：每段只按角色、道具、场景参考图独立生成，不带首帧、不等上一段。同一集满足条件的段一起提交，实际同时生成数受「同时生成数」和账号活动任务上限约束。段视频提示词不再要求段尾硬定格；画布「采用到短剧」只替换本段，不提供级联重生成。只支持参考图生视频、不支持图生视频的模型只能用并行出片，保存设置时会校验。

## 短剧步骤配置、表演运镜与视频分辨率

- 文字步骤：资产提取、分镜拆分、视频提示词每一步可以单独选文本模型和写作技能（来自「我的技能」），不选就用默认文本模型和内置写法。资产提取与分镜拆分的输出结构由系统固定，技能只决定取舍和写法。要微调写法，在技能库里改自己的技能，下一次执行就读新内容。
- 参考图：角色、道具、场景可以分别选图片模型与分辨率档位，不选沿用默认图片模型。设定详情除了上传形象图，也可以从素材库选图片（角色还可选角色卡的当前形象），选中后替换并锁定。
- 镜头节奏改为五档滑杆（极快 / 快 / 标准 / 舒缓 / 慢），新作品默认快节奏，转场时长默认 150 毫秒。
- 分镜规则新增「表演强度」（内敛 → 克制 → 自然 → 饱满 → 夸张）与「运镜动感」（静态 → 稳定 → 标准 → 动感 → 强烈）两个 1–10 档滑杆，写进剧本与段视频提示词的表演、台词语气和运镜要求。尾帧续接的段末只收势 0.5 秒，不再整段硬定格。
- 新建页与制作设置可以选剧情段视频分辨率，档位来自所选视频模型；按段或批量换模型时，给不出该分辨率的模型置灰。
- 段视频提示词按视频模型的提示词上限撰写，超出时自动精简；剧情段弹窗显示发送全文字数与上限。

管理员可以安装官方插件「WAN 3.0 拼车中转（班次发车）」（`coolhs-wan3-relay`），把 `wan.coolhs.com` 的 `/api/portal` 接口配置成系统视频渠道，卡密写在渠道 API Key 里。插件的处理流程：

- 素材：先上传参考图、视频、音频拿到素材 ID；短剧的“参考图N”原样作为素材 token。
- 交单：用平台幂等键作为任务 `id`，有参考素材时关闭官方扩写。
- 等待：提交后释放执行位，每 15 秒回查一次，任务进度显示“候车 · 前面 N 条 / 已发车 / 出片中”。
- 出片：成片链接是临时地址，出片后立即下载转存。

中转站的首尾帧不能与参考图混用，短剧使用该渠道时请选择并行出片。插件字段见 `plugin-packages/coolhs-wan3-relay/docs/interface.md`，宿主能力见[统一插件运行时](/docs/backend/protocol-plugins)。

## 推广中心

- 独立声明式协议支持可灵 v4 的文本生成、首帧及全能参考；模型名不锁定，复用前须核对相同接口及能力范围。
- “卡藏 可灵视频 4.0”协议自动配置 6 秒、720p、16:9；可选 3–30 秒、720p/1080p 和四种比例。图片/视频/音频最多 10/5/3 项，合计 15 项；参考视频逐条传时长，合计不超过 30 秒。不支持尾帧，界面隐藏该选项，后端仍做校验。
- 后台测试支持自定义提示词，视频按当前默认参数生成，并保存预览和下载结果；不创建用户计费订单，不要求先设置价格或启用模型。仍会产生供应商费用并占用账号存储。
- 售价与成本由管理员独立确认；任务按 ID 查询和恢复，临时成片由宿主持久保存，不自动重试创建。

## 音乐生成

- 文本音乐协议支持 Suno v6 及相同接口的模型，不限制模型名称；用户选择歌曲或纯音乐，描述曲风、心情、乐器和演唱方式即可生成。
- 选协议自动配置输入上限、纯音乐选项、单次任务和非流式输出；默认按实际返回保存所有音频，管理员可按模型合同调整参数与请求等待时间。生成只提交一次，结果下载恢复不会重新创建音乐。

## 二字导航

- 用户外壳采用左对齐一体式：224px侧栏、72px品牌区与顶栏、32px原Logo、22px品牌、16px菜单和48px导航行。品牌文字与菜单文字对齐，顶栏只显示当前页面名称；品牌区与侧栏同底色，顶栏与正文同底色，明暗主题下都不形成横向色带。
- 用户侧栏、收起模式、顶栏和页面搜索共用二字入口：创作、短剧、画布、图片、视频、技能、插件、素材、历史、邀请；分组标题为工具、管理，品牌区只显示品牌名称。
- 完整功能名称保留为悬停提示、无障碍名称和搜索别名；旧名称仍可搜索，图片与视频工作台按独立功能开关显示。
- 手机菜单独立于桌面收起偏好，打开后显示完整图标与二字名称；支持导航后关闭、遮罩关闭、Esc、焦点约束和焦点返回。

## 通用精灵宠物

- C 端右键贴边扇形菜单支持形象选择、大小滑块、锁位置和暂时收起；手机长按或从 Agent 设置进入，账号偏好跨设备保存。
- 后台形象库可发布、排序和设默认，默认大小使用滑块；未发布资源不向 C 端公开，资源引用受删除保护。

- 画布 Agent 支持动态球、Live2D 和精灵宠物三种形象，不绑定固定角色；支持 Codex v1/v2 ZIP 和自定义 PNG/WebP 图集。
- 后台可编辑动作帧、速度、循环、业务状态映射、注视及可选睡眠，支持试播和配置导出。详见 [精灵宠物](/docs/overview/sprite-pets)。

## 爱困 Gemini 视频 · omni-flash

## RollDek Gemini Omni 与 Veo Fast 视频

`rolldek-gemini-video` 是独立声明式插件，提供 `rolldek-gemini-omni-video` 与 `rolldek-veo-fast-video` 两个协议。选择协议自动填充“能力与参数”：Gemini 默认 4 秒、720p、16:9、单条，可选 4/6/8/10 秒和竖屏；默认普通参考图 1 张及首尾帧各 1 张，图片合计 3 张，视频/音频各 1 项。普通参考图与总图片上限可分别在后台调整，数量是平台配置而非供应商极限。首尾帧使用独立上游字段，普通素材数组保序。

真实验证发现 `generateAudio:false` 仍返回有声 AAC，因此暂时隐藏生成音频开关，明确音轨由上游决定；参考音频输入继续支持。测试另行导出的无声副本不代表在线生成会自动移除音轨。

Veo Fast 仅开放公开示例的 8 秒、720p、16:9 文生视频；Veo Lite 暂不开放。插件使用原生顶层 JSON、同任务查询及鉴权下载，排队 URL 不会提前标为完成，查询/下载重试和任务恢复不重新创建付费任务。协议切换不自动定价或启用模型。

## 卡藏 Gemini 语音合成

`kacang-gemini-tts` 是独立声明式插件，适配 `gemini-3.8-flash-tts` 的原生语音接口。选择协议自动填入纯文本朗读、Kore 默认音色、30 个预置音色、默认声音指令、非流式单段 WAV，以及供应商公布的输入/输出 token 上限。生成时可选音色与演绎指令；多段 PCM 按顺序解码拼接后保存为 24kHz 单声道 16-bit WAV。错误、缺失音频或截断样本不标为成功。每次按请求计费，售价与启用状态需独立配置。

## 邀请返利

正常用户可通过邀请码邀请新用户注册，被邀请人的每次在线充值按到账积分产生单层返利。支持全局及个人比例、可选冻结、部分或全部转入积分、管理员暂停与作废剩余返利。默认活动关闭、全局比例 0，上线后由管理员配置开启。详细规则见 [邀请返利](../backend/invitation-rebates)。

用户端「邀请有礼」页面采用海报式首屏（站内短剧与电商作品拼贴、复制邀请链接 / 文案 / 邀请码、规则弹窗）与排版式收益区（细线数字条、单色时间轴、账单式记录），面向用户统一称「奖励 / 领取 / 领进钱包」，后台与接口仍沿用返利、转入等字段名。

## 卡藏视频

`kacang-video` 声明式插件提供 Gemini Omni Flash 1.1、Grok Imagine Video 1.5、可灵 3.0 特惠以及 Grok 1.5 Fast、线路八五个专用协议。选择协议自动填写视频能力、参考素材限制和默认时长/分辨率：3 秒/720P、8 秒/480P、5 秒/720P，Fast 与线路八均为 6 秒/720P，默认 16:9。Fast 与线路八最多七张图片，支持 720P/1080P 和五种比例；Fast 多张参考图最长十秒，提交前拒绝超限。按各线路公开 JSON 字段提交，统一查询及鉴权下载；相对结果地址使用鉴权内容端点。精细素材角色与限制见插件包的完整接口文档。

## YuxiBox SD 视频

`yuxibox-sd-video` 声明式插件提供 Seedance 2.0、2.5 按秒及按次三个协议。选择协议自动填入固定 720P、16:9、官方时长与参考素材上限；2.0 支持 5/10/15 秒，2.5 支持 4–30 秒。JSON 请求按顺序传递图片、视频和音频 URL，异步查询及鉴权下载由宿主执行。完整合同见插件包内 `docs/interface.md`。

自定义站点品牌在公开外观配置加载成功后展示。配置尚未确认时使用中性加载界面；首次加载失败提供重试，不把内置品牌当作成功结果。工作台、登录页和欢迎页共用这一配置来源。

浏览器标签图标由当前已保存品牌标记独立生成，提供透明背景的小尺寸 ICO、PNG 和 Apple Touch Icon，不添加方形底板或边框，不随网页或画布主题切换。彩色标记使用更大的有效区域，不添加统一反色描边；黑白标记保留细微抗锯齿对比边缘。首屏可直接获取当前图标；外观版本与确认缓存一致，成功访问后接口暂时不可用时可恢复已确认品牌。后台品牌页的浅色、深色标签预览直接使用 ICO 对应的原生 16/32 像素帧，站内两套 Logo 保持各自用途。

## 968API SD 视频

独立 `yingce.plugin/v2` 声明式插件覆盖 `sd-2.0`、`sd-c2`、`sd2.5`、`sd2.5-15`、`sdmini`。选择对应协议即填入“能力与参数”的模型默认值，使用专属视频创建和查询端点；图片映射为 `image` / `images`，音频映射为 `audio_refs`。默认横屏 16:9、720p；SD 2.5 固定 30 秒，SDmini 默认 8 秒，其他协议默认 15 秒。

SDmini 的时长按分辨率校验：720p 最长 12 秒，480p 最长 15 秒。生成面板切换分辨率时调整时长，服务端及插件再次拒绝越界请求。其余模型只支持 720p；各模型的参考数量与固定音频行为见插件包内 `docs/interface.md`。供应商未声明的单文件大小及音频时长不新增猜测限制，仍受平台上传限制约束。

## 首页 Agent 创作

各模式创作对话使用稳定的 `/c/:id` 私有地址，可复制、刷新、前进后退及同账号跨设备打开。普通模式必要历史保存到服务端，Agent 正文仍使用原生会话记录；无法访问或已到期的链接显示明确提示。管理员在“资源与策略”设置独立的历史会话保留天数，默认 0 长期保留，历史抽屉显示实际期限并提供管理员设置入口；到期清理不取消活动任务，也不删除账务和媒体。
首页 Composer 左下角的"创作类型"菜单提供 Agent（交给阿Q规划）、图片生成、视频生成、音乐生成和音频生成，只放生成类型，每项只有图标和名称，选中项打勾；图标与首页工具入口共用一套（`components/creation/creation-type-icon.tsx`）。音乐生成只列歌曲、纯音乐模型，音频生成列配音、音效等其余音频模型，没有对应模型的一项不显示。偏好包含简洁/详细输出、默认图片/视频/音频模型、参数约束和预算，并随账号保存。结果图悬停（触屏常驻，大图预览里常驻在图片下方）出现图片工具条：变体、高清、局部重绘、扩图、消除、转视频、作为参考，以及按用途分组的「更多」菜单；创作类型是 Agent 时「作为参考」排在第一位，其余顺序不变。转视频和作为参考只把这张图放进输入框；其余工具参考即梦先打开弹窗，选好参数后直接生成，结果接在对话末尾，见下方「图片工具」。Agent 支持只读、请求审批和自动执行，上下文圆环展示下一次请求占用。多图按批次堆叠、切换及展开预览，方形卡片居中裁切而原图预览与下载保留完整画幅。每张图片、视频结果（直接生成、Agent 直接执行和方案卡里的都一样）在图下操作行最后用文字标出实际像素（如 1024x1360）：资源结果用资源记录里的原图像素，不等图片加载，图上显示展示档位时也标原图像素；记录里没有宽高时（视频常见）等加载出来再标。叠图标最前面那张，展开成网格后不标。Agent 任务在受理事件里带回实际提交的尺寸，生成中的占位按它预留画幅，不再先显示方形。进度按真实计划图片总数计算，失败项统一重试。执行计划展示创作阶段，完成项划线；重要信息按当前意图选择展示，允许用户补充。

首页会话由服务端保存，历史列表先加载标题，点击后读取内容；智能创作记忆沿用个人记忆的待审/批准流程。独立图片先规划后批量提交，停止只中止后续 Agent 编排，已受理媒体继续生成和计费。URL 结果优先展示，浏览器补存与后台恢复不阻塞下一轮。完整边界见 [首页创作 Agent](../backend/creative-agent-runtime)，合并后的待验项目见 [待测试](../progress/pending-test)。

明确失败且未改变生成设置的图片、视频直接复用原提示词和逐项素材重试；内容审核拒绝才进入提示词修复，未知提交先核对原任务。图片和视频模型分别支持优先使用或固定型号，兼容切换保持素材与规格，重试共享原轮剩余积分预算。

同一会话从图片或视频切回 Agent 时，带入最近普通创作记录、受管参考素材和任务身份，由服务端核实状态和成品归属。重试按原消息的生成模式及任务状态处理，批次只重试确认失败的项目；跨浏览器可以用原操作标识恢复提交回执。

### 输入框工具栏与技能

- **工具栏（参考即梦）**：输入框底部的「Agent 模式」、模型、偏好、技能、生成方式和各类参数按钮都是幽灵按钮：不铺底、不画框，文字用正文色，悬停或展开时才出浅底，控件间距 4px。模型按钮宽度跟着模型名走；后台展示名是默认的「未分类」时，只显示模型本身的名字。
- **技能**：Agent 模式下，「偏好」和生成方式之间是「技能」。菜单列出技能库里已安装的技能，可以搜索；和画布助手一样，选了就能用。点一个就在提示词末尾插入技能标签（和输入 @ 选技能一样），再点一次取消；一次最多 4 个，按钮上显示已选个数。发送时，提示词里的技能标签、@名称、/名称都会固定到本轮（`skillIds`，最多 16 个）。不选时，首页 Agent 只会自己查找声明了首页入口（`agentSurfaces` 含 `creation`）的技能。作者声明只给画布用（`agentSurfaces: ["canvas"]`）的技能不出现在这里，也不出现在 Agent 模式的 @ 菜单里。游客点开时提示登录。空态切到「画布」时没有输入框，也就没有这个按钮。
- **技能商店**：「技能」菜单底部的「管理技能」（没有可用技能时是「去技能商店看看」）在当前页打开技能商店弹窗，和画布助手的技能商店是同一个，草稿留在输入框里。可以按我的技能分类、技能广场分类和关键词找技能，未加入的点「加入」，已加入的点「使用」在提示词末尾插入技能标签，再点取消；右上角显示「已选 N / 4」。作者声明只给画布用的技能显示「仅画布」，不能选。技能广场读不出来时显示原因和「重试」。

### 生成方式、提交即返回与按预估授权

- **生成 | 画布**：空态标题下的分段切换，在本页原地切换并写进地址栏（参考 kunrouai.com/?mode=canvas）：选「画布」是 `/create?mode=canvas`，选「生成」去掉参数；每次切换压一条历史，后退回到上一面，刷新、从画布页返回都停在同一面，`mode` 是其他值时按「生成」处理。不写进偏好；从侧栏「创作」、新对话或灵感「做同款」进来是「生成」。两面的标题和副标题分别在后台「外观设置 → 创作首页」配置。画布面和 kunrouai.com 一样不显示输入框：切换下面先是一行「新建画布」加最近更新的 3 张画布（封面拼图、名称、节点数和更新时间，点了进入画布）。「新建画布」建空白画布并进入，游客先登录；游客和还没有画布的账号只有这一张，铺满整行。中等宽度一行三张，手机两列。再往下是首页同一套「精选画布」：5 张，「全部画布 · N」进 `/inspiration`，点卡片打开同一个复制弹窗，游客复制前先登录。以前画布面「点发送新建画布并交给阿Q」的入口已去掉，画布页仍认 `?agentPrompt=`。
- **提交即返回**：Agent 模式下阿Q 提交图片、视频或一组图片后，受理即结束这一轮（工具回执 `phase:"accepted"`），结果完成后直接出现在对话里，不再占着 Agent 等结果。只有同一轮下一步要用新成品（例如先出图再用这张图做视频）时，阿Q 才传 `waitForResult=true` 等真实结果。整套商品计划仍等整套结果。
- **按预估授权**：Agent 模式发送键上显示"约 N 积分"（按当前图片模型出 1 张图估算）。"请求审批"（`request_approval`）下点发送即同意 N × 1.2 以内的消耗：本轮累计报价在这个额度内的方案直接执行，超出才出现确认卡；确认一组图片时如果报价已过期、且新报价不高于原报价，自动按新报价执行；涨价时显示新报价，请用户再确认。"自动执行"（`auto`）和"只读"不变。创作页生成方式菜单的这三项名称和画布助手一致。
- **音乐生成 / 音频生成**：两项都只收文字，提交的仍是音频任务（`mode: "audio"`），按模型能力配置里的生成类型（`generationType`）区分，没有该配置的旧渠道按协议判断（`kacang-suno` 为音乐）。音乐生成在设置里选歌曲或纯音乐，一次返回几首就显示几条播放器；音频生成在"音频设置"里调音色、格式、语速（只在本页生效）。两类共用账号偏好里的音频模型，切换类型时本页记住各自最后用的模型。结果是播放器加下载，不进画布、不进阿Q 的普通创作上下文。
- **历史同步**：每个会话最后一次成功写入云端的历史摘要记在本机（按账号隔离），重新打开创作页时内容没变的会话不再整份重传。

### 图片工具（结果图）

交互参考即梦：点工具打开弹窗，左边看图和操作，右边选参数和模型，点生成直接出图；结果作为新的一组消息接在对话末尾，可以继续套用工具。工具不改输入框：不写图片偏好，提交按图片模式发出后输入框回到原来的创作类型。弹窗里的模型默认取输入框的图片模型，它不能收参考图时换成第一个能编辑图片的模型；不能收参考图的模型在列表里置灰。除高清外，尺寸都按原图（或工具约定的画幅）比例取输入框当前的清晰度档位。画布图片节点上能单张出图的工具都在这里有入口；全景、图层拆分、预演台、表情和质感依赖画布节点，只在画布上提供。

- **变体**：选变化方向（构图、光线、角度、姿势、场景、配色、风格，可多选）、幅度（轻微 / 明显）和张数，原图作为参考再出几版。
- **高清**：列出与原图同比例时模型能出的每一档清晰度（1K / 2K / 4K，附输出像素），默认最高档，质量参数一并调到最高；平台没有独立的超分模型，这是"重绘成高清版"。只想放大像素用「更多 → 调整尺寸」。
- **局部重绘 / 消除**：在图上用画笔涂抹，可切换橡皮、调笔刷、撤销重做（`[` `]` 调笔刷，⌘Z 撤销）。局部重绘写下要改成什么；消除不用写，用背景补全涂抹处。模型支持蒙版时只改涂抹区域；能收两张参考图时附一张半透明红色涂抹标注图；只收一张时按涂抹外接框的百分比坐标定位。
- **扩图**：选画幅（原比例、1:1、4:3、3:4、16:9、9:16、3:2、2:3）和倍数（1.5× / 2× / 3×，换画幅时可选"仅补齐"），可以拖动或用方向键移动原图在新画面里的位置。底图四周铺模糊边，模型支持蒙版时附蒙版（新增区域透明，接缝处向内留一条窄带）。
- **更多 → 局部编辑**：区域标注（画布的框选弹窗，@区域N 分别描述）、文字编辑（打开即用文本模型识别文字，逐行改写后生成）、去除背景（模型支持透明背景时输出透明底，否则换纯白底）。
- **更多 → 光影与镜头**：打光、多角度直接用画布的面板；电影级光影校正、画面推演（5 秒前 / 3 秒后）用平台内置的同名提示词工具。
- **更多 → 宫格与设定**：多机位九宫格、剧情推演四宫格、25 宫格连贯分镜、角色三视图、角色脸部三视图、产品三视图，与画布同一批后端提示词工具（`@[tool:nine_grid:…]` 由后端展开并校验），按工具约定的画幅出图；对话里只显示工具名和补充要求。
- **更多 → 图片工具**：裁剪（裁好放进输入框作为参考）、调整尺寸（插值放大后下载 PNG，不调用模型）、宫格切分（按行列切开，打包下载或放进输入框，超出模型参考图上限的部分不加入）、反推提示词（文本模型看图写提示词，可复制或填入输入框）。
- **重做**（图下一行）：单张结果的下载只留图片右下角的按钮，图下一行的「下载」换成「重做」；多张结果保留「批量下载」，「重做」排在「添加到画布」后面。点「重做」打开同一类弹窗：左边是这张图（叠卡时是最前面那张），右边是原提示词（可改，改过可一键恢复）、原参考图缩略图、尺寸和张数，底部是模型和本次积分。模型默认用这张图当初的模型；原模型下线或收不下这些参考图时换成输入框的图片模型或第一个收得下的模型并说明原因，收不下的模型在列表里置灰。尺寸默认用当初的尺寸（Agent 结果取任务实际提交的尺寸，旧记录取方案卡上的），所选模型不支持时按比例和档位换到最接近的一项，没有记录时按这张图的实际像素换算；张数默认和原来一样。确认后按图片生成提交一次新任务（会再扣一次积分），结果作为新的一组消息接在对话末尾，原图保留，输入框不变。直接生成取前一条用户消息的提示词和参考图；Agent 结果取模型写下的原始提示词（工具调用参数，没有时用方案卡或整套方案里的提示词）和任务实际带上的参考图。还在生成、状态待确认、智能创作批次和多个 Agent 任务拼成的一组（每张提示词不同）不显示「重做」。

### 方案卡、联网与视频合成

- **逐项方案卡**：需要确认的多图批次和单项生成按每项一张卡展示提示词、画幅、质量（视频含时长）、模型和单项积分。可以在卡片里改提示词和参数（服务端重新报价）、把不要的项标为暂不生成，再"一键确认"。确认后每项不再套卡片外框，和普通生成结果一样直接显示在对话里：标题和「查看方案」在上，生成进度和结果图在中间，图下一行和普通结果相同，是「添加到画布」「重做」（下载在图片右下角），最后是实际像素；模型、参考数等其余参数收进「查看方案」。整套商品计划的卡片只读，仍用"按备注修改方案"。手动参数模式下只能改提示词。
- **工具进行中**：每个工具执行时先出现一行"正在查看创作素材…""正在联网搜索「关键词」…"，结束后原地换成结果行。
- **浮动创作计划**：本轮执行计划显示在对话区右上角，宽屏默认展开，可收起。
- **联网搜索与网页读取**：管理员在「平台配置 → 联网搜索」配置 DeepSeek、博查、秘塔、智谱、Tavily、Serper 或自建 SearXNG 并开启后，Agent 可以联网搜索；创作页「偏好」里出现「联网搜索」开关（存账号偏好，换设备沿用），用户可以自行关闭。画布助手同样可以联网：「Agent 设置」里的「联网搜索」与「偏好」里是同一个开关，搜索期间对话末尾显示「正在联网搜索「关键词」」，结束后工具行列出来源。网页读取不需要配置，可选接入 DeepSeek Fetch（与 DeepSeek 搜索共用 API Key）或 Jina Reader（云端或自建开源版，能读脚本渲染的页面和 PDF），只在服务端直接读不到正文时才用。回复里的引用写成来源链接，工具行显示关键词和来源数，本轮结束后回复末尾汇总「参考了 N 个网页」。每人每天的搜索次数可设上限，10 分钟内相同的搜索直接复用结果。管理员可设每次搜索消耗的积分（按用户分组折扣）：只对搜到结果的搜索扣，搜索失败、没有结果或复用结果不扣，计入本轮「单次花费上限」，读取网页不扣；用户在「偏好」里能看到每次的价格，工具行写出本次消耗，积分明细和用量看板单独列出「联网搜索」。
- **视频合成**：Agent 可以把本会话已完成的视频和图片按顺序拼成一条成片，叠加你上传的音频作配乐或配音，加字幕（默认烧录进画面，另附 SRT）。在服务器本地合成，不消耗积分、不需要确认，成片出现在"视频合成"卡片里，卡片上可下载成片和 SRT 字幕。依赖服务端 ffmpeg 与 ffprobe（ffmpeg 可用 `CANVAS_FFMPEG_PATH` 指定，留空时在 PATH 中查找；ffprobe 只在 PATH 中查找）；烧录中文字幕还需要中文字体，后端镜像已安装 `font-wqy-zenhei`，本机 ffmpeg 不支持时自动改为不烧录。详见 [首页创作 Agent](../backend/creative-agent-runtime#视频合成)。

## 首页（启动页）

首页参考 leyi.my 的启动页布局，自上而下为：新建画布创作、工具入口、精选画布、精选灵感；Agent 对话创作移到「创作」（`/create`，会话链接 `/c/:id` 不变）。侧栏为「首页 / 创作 / 项目 / 画布 / 灵感」，下方是可折叠的「资源与工具」（素材、生图 / 视频工作台、技能、插件）和历史；游客在左下角看到主题色的「游客模式」卡片与登录入口。顶栏高 56px 且不单独铺底色，与下方页面无色差。

桌面端（宽度 ≥1024px）界面整体按 90% 显示：浏览器 100% 时就是以前浏览器缩放 90% 的大小，浏览器再放大缩小按同一比例叠加；铺满窗口的外壳、加载页按比例补回高度，拖拽、光效等按指针位置计算的交互和悬停提示已换算坐标。画布编辑器、分享画布和开发实验页保持原尺寸，手机宽度不缩放。工作台默认深色主题：新访客和此前未改动主题的用户打开即为深色，之后手动切到浅色会被记住。

- **新建画布创作**：点阵卡片带光效（亮点从中心扩散、跟随鼠标的光斑），点击直接新建空白画布并打开；游客先弹登录框。
- **工具入口**：短剧 Agent、视频生成、图片生成、音频创作、剧本生成、素材管理、提示词技能、模型设置，只接已有功能——视频 / 图片进入工作台（工作台关闭时改为新建画布并放好对应节点），音频创作与剧本生成新建画布并自动放好音频或剧本节点，模型设置直达设置页「模型选择」；短剧项目关闭时不显示短剧 Agent。
- **精选画布**：后端 `/api/libtv/featured` 读完 LibTV「精选画布」标签和公开作品流，收录全部满足条件的作品，不设数量上限：有成片和横版封面（宽高比 ≥6:5），节点 ≥100；复制后节点、连线和媒体结果一个不少，复制出的画布不超过 3MB（服务端单画布上限 4MB）；跳过活动 / 品牌广告赛道和人工复核出的水印、广告作品。「精选画布」标签的作品排在前面，各自按点赞排序。每个作品的复核结论按快照版本缓存，没重新发布就不再读详情；列表缓存 30 分钟，服务启动即后台预热，首次构建先放出排在最前的约 20 个。首页展示前 5 个，「全部画布 · N」进入展示全部精选的画布页；卡片显示「可编辑画布 · N 节点」，点开为精简弹窗（封面、作者、节点 / 连线 / 提示词数量、复制并打开画布，来源信息折叠，可进入完整制作过程）。
- **精选灵感**：与灵感库同一份目录（含个人隐藏与自定义），按全部 / 视频 / 图片 / 文本筛选，有视频样片的排在前面，下滑分批加载；鼠标悬停时静音循环播放样片（触屏与减少动态时不自动播放）。点卡片进入创作页并开新对话预填提示词，不自动生成。「全部灵感」与侧栏「灵感」进入 `/inspirations` 灵感库（标题与导入 / 导出 / 新建、类型、分类标签、筛选行、卡片网格，下滑加载），创作页灵感区共用同一组件。

## 手机端（≤720px）

手机上侧栏收进左上角菜单抽屉，底部常驻四个标签，页面只保留浏览、创作和账户相关的操作，参考 LibTV 的手机布局。

- **顶栏**：菜单键、品牌标志与当前页标题；右侧登录后只有积分余额和通知，游客只有主题切换与「登录」。反馈、头像菜单收进「我的」。
- **底部导航**：首页、创作、画布、我的。从某个标签进入的二级页面仍高亮该标签（灵感、全部画布、短剧和工作台归「首页」，素材、创作历史、技能、邀请归「我的」）。游客点「画布」「我的」时就地弹出登录框，登录后前往该页。正在输入时导航收起，把高度让给输入框。
- **我的**：底部导航进入 `/settings`，上方是账户卡片（积分与充值 / 兑换、邀请入口（开启邀请活动时）、更新日志、外观、退出登录），中间是我的画布、素材、创作历史、技能库四个入口，下方列出个人信息、用量看板、模型选择、生成偏好和我的反馈。渠道、RunningHub、提示词偏好、Agent 记忆、对象存储与问题诊断不在列表里，用链接仍可打开。
- **页面精简**：技能库为「技能广场 / 我的技能 / 我的收藏」文字标签加分类横滑（吸顶）、整行搜索和单列卡片，主操作为「加入」；安装技能、行业推荐、排序、分类管理与「我创建的」只在桌面端。灵感库隐藏导入 / 导出 / 新建灵感、来源筛选和卡片「更多」菜单。画布列表隐藏导入画布包。页头说明文字、每页条数与跳页不在手机上显示。创作页输入框的 Agent「偏好」「技能」只显示图标（深度思考、联网搜索在偏好里，选了技能时图标带个数），隐藏上下文用量环，对话页顶栏为两行（标题与积分一行、镜头时间线与新建 / 历史一行），「画布中继续」只在桌面端显示。
- **浮层**：创作页不再显示浮动 Agent 入口；弹窗和抽屉打开时入口收起；其他页面的入口停在底部导航上方（含 iPhone 底部安全区）。新用户的「先选择创作模型」引导卡横向铺满并停在底部导航上方，已在「模型选择」分区时不再显示。
- **画布编辑器**：默认普通布局（不进专注模式）。顶栏为菜单、画布名称、同步状态、积分与分享，专注模式收进菜单；左侧菜单不显示，节点、素材库、任务和历史从底部「工作区」打开，抽屉顶部切换分类。底部工具条为撤销、重做、添加节点、素材库、工作区和选中后的删除；缩放条只留适应画布与缩放。打开时一个完整节点都看不到会按可读比例重新取景。点节点后生成面板从底部弹出，节点自动移到面板上方；Agent 入口停在工具条上方，面板、菜单和添加节点面板打开时让开。
- **画布触屏手势**：单指拖动空白处或未选中的节点平移画布，轻点选中；已选中的节点单指拖动即移动。双指缩放和平移。长按节点、连线或空白处打开对应菜单（iPhone 也可用）。双击沿用桌面端的双击操作，如预览图片、展开图片组、打开预演和空白处新建节点。框选和多选仍需在桌面端完成。
- **其他触屏交互**：触屏设备（含平板）上画布卡片、素材卡和创作历史列表行的多选、更多与重试常驻显示；灵感详情可直接播放视频样片；模型可用率轻点即可展开；手机上的输入框统一 16px，避免 iPhone 聚焦时放大页面；预览视频在页面内播放，不强制全屏。

## LibTV 灵感广场

首页“精选画布”的“全部画布”进入灵感广场；灵感大厅独立为 `/inspirations`。游客与登录用户均可在灵感广场搜索、按标签筛选和分页浏览 LibTV 公开作品，查看成片、制作步骤、公开提示词及图片、视频、音频预览。
可独立复用的步骤支持预填到创作页，不自动生成；含引用的模板可复制到新画布，预览转换警告并确认导入，保留节点、连接、画框和多个媒体结果。公开作品查询不需要管理员的 LibTV 凭证；原有私有项目导入设置保持独立。

## 画布多窗口实时协作

同一账号在多个窗口打开同一画布时，在画布顶部正中间以紧凑入口显示在线设备数量，展开后查看“设备1、设备2”等会话。服务端统一编号，各窗口名称和颜色一致，自己所在行标记“此窗口”。只显示远端光标的小标签和轻量拖拽轮廓；只剩一个窗口时全部隐藏并停止采集光标。高频坐标按帧直接更新独立浮层，不触发 React 重渲染。WebSocket 广播临时预览和提交后的同步通知，最终内容仍经过原有 operations 保存与并发合并；正常空闲连接改为低频状态校验，断线保留轮询。未配置 Redis 支持单后端进程，配置后支持跨实例分发；不增加跨账号编辑权限。真实浏览器与部署验收见[待测试](/docs/progress/pending-test)，协议见[画布操作同步](/docs/backend/canvas-operations-sync)。

## 用量看板

设置页“账户 → 用量看板”（`/settings?section=usage`，积分功能开启时可见）展示最近 365 个自然日的积分消耗，可在“总用量 / Agent 用量”之间切换：

- 五项指标：总消耗、单日峰值（及日期）、周均消耗（按 52 周折算）、活跃天数、最长连续活跃天数（及当前连续天数）。
- 积分活动图：每日热力图（周一为每列第一行，颜色按有消耗日期的四分位分 4 级，峰值总是最亮）、每周柱状图、累计曲线，三种视图共用同一月份刻度；悬停或聚焦后用方向键逐日 / 逐周查看数值。每日、每周视图里点击格子 / 柱子（或用方向键）选中某一天 / 某一周，选中项常驻描边。窄屏可横向滚动，默认停在最近一周。
- 消耗构成：跟随积分活动图，每日视图展示选中的一天（默认今天），每周视图展示选中的一周（默认本周），累计视图展示最近 365 天；切换视图时回到最近一天 / 本周，切换总用量 / Agent 用量时保留所选日期。可在“按类型 / 按模型”之间切换：按类型汇总图片、视频、音频、文本、其他的金额、笔数与占比；按模型列出当前口径消耗最多的 12 个模型（其余合并为“其他 N 个模型”，只多出 1 个时直接列出），显示前台模型名称、类型、笔数、平均每笔、积分与占比，不显示供应渠道或线路。
- “消耗明细”打开积分中心的消耗历史；积分中心的消耗历史也提供“用量看板”入口。

日期按浏览器当前的 UTC 偏移划分（整年共用同一偏移，夏令时地区跨季节的零点附近消耗可能落到相邻一天），只统计实际扣费（结算后的 consume 流水），不含冻结、退款与收入；接口见 [HTTP API 合同](../backend/http-api#用量看板)。

## 生图与视频工作台

普通用户可分别使用图片（`/toolbox/image`）、视频（`/toolbox/video`）生成页，面向电商出品：左侧创作面板选择出品场景（场景库按分类和电商细分浏览）、上传或从素材库选择商品素材、套用场景模板并用灵感词补充描述，按所选模型能力设置规格（比例标注主图、服饰主图、竖屏等用途）；一次可生成多张图片或多条视频，页面按模型单次张数和账号并发拆成多个任务并汇总预估积分，部分任务未提交时可继续提交。右侧作品画廊按批次展示进度与结果，支持取消、重新生成、下载全部、复用参数、用作参考图、图片做成视频和大图预览。管理员在「工作台工具」维护分类、图标/封面、预设、使用说明与示例素材，并在「功能开放」分别控制两个入口。新入口默认关闭；不会自动安装预设、启用模型或调整价格；工作台任务经过统一任务与计费服务创建。

接口合同及待验收边界见 [HTTP API 合同](../backend/http-api)。

## 可美 KM Seedream 图片

`km-kemei-seedream` 声明式插件接入 Seedream 5.0 Pro / Flash 的文生图与参考图编辑，支持 URL / Base64 响应并由宿主统一保存图片。精确模型 ID 与扩展参数见插件包内 `docs/interface.md`。

协议默认 2K 方图、单张生成、最多十张参考图，提供 1K / 1.5K / 2K 共二十四个精确尺寸预设。后台能力编辑、画布选择与服务端校验同步支持 1.5K。蒙版与通用质量开关关闭；透明输出通过插件命名空间配置，并要求单张含 alpha 的参考图。供应商错误和空结果保留失败语义。

## 卡藏 Midjourney

画布接收一次任务返回的全部图片，四张结果自动组成收起的图片堆叠，可展开、选择主图和分别使用。每张图保留独立资源及素材绑定，保存、刷新和任务重复同步不会将后续图片覆盖为第一张。已有仅显示首图的成功 Midjourney 节点在重新打开画布时从原任务恢复遗漏结果，无需再次生成。

`kacang-midjourney` 统一声明式插件提供 V6/V8 特惠、V7 特惠、稳定/高速三个生图协议。选择协议后自动填入供应商比例、默认比例、参考图上限和一次提交；禁用无合同的蒙版和通用输出参数。稳定版数值 quality 通过插件命名空间设置，不与宿主分辨率档混用。

特惠使用标准图片端点，稳定/高速使用受理和任务查询端点。结果支持顶层与 data 信封，全部单图及可选四宫格封面交给宿主立即保存；失败和空结果保留真实失败语义。完整模型和字段合同见插件包内 `docs/interface.md`。

## 存储空间套餐

账号文件容量由后台全局基础容量和用户购买的扩容组成。管理员在「支付 → 充值商品」新建“存储空间扩容”类型的商品，设置容量（整 GB）、有效期（按天或永久）、价格和上架策略；用户点击侧栏或素材页的容量入口打开存储空间弹窗，查看已用、基础与已购容量，购买扩容并查看扩容记录。多份扩容的容量叠加，各自按有效期到期。积分功能关闭时存储空间商品仍可购买。

已用超过容量后立即暂停上传和生成；7 天宽限期结束仍超额时账号只读，只能查看、下载、删除素材、购买空间和修改账号设置。删除素材或扩容后刷新容量即可恢复。管理员可在用户详情的「存储空间」页赠送或撤销扩容。

## 沧元 Midjourney

`cangyuan-midjourney` 声明式插件分别提供 V7 与 1K/2K（供应商默认 V8.2）协议。V7 使用 `midjourney-v7`；1K/2K 使用 `midjourney-1k`、`midjourney-2k`，可在提示词显式写 `--v 8.2`。一次提交固定 `n=1`，全部结果交由宿主下载保存，参考图按供应商合同发送 HTTPS URL 字符串。

两条线路的参数、编辑端点和响应格式分别适配，不自动换模型。1K/2K 返回官网 CDN 原链，HTTP 403 会如实保留保存失败与原任务重试能力；插件不能消除供应商 CDN 的访问限制。完整字段与接口合同见插件包内 README 和 `docs/interface.md`。

创作页按整个任务一次消费返回图片，保留各图片的输出序号；一次请求返回多张时，素材与消息幂等去重不会再把后续结果当作第一张合并。

后台选择这两个协议时，“能力与参数”自动使用线路专属默认值：V7 为 4000 字符、五张参考图、不支持蒙版；V8.2 默认单张编辑源图、支持蒙版和十五种比例。两者默认自动尺寸、一次提交，关闭不支持的质量、透明背景、响应格式和输出格式选项。V8.2 在模型名未明确时暂用 1K，识别到上游 `midjourney-2k` 后改为 2K，切换档位保留管理员的参考限制、默认比例和价格。像素预设由宿主换算供页面展示，提交上游仍使用比例，实际尺寸由供应商决定。

## AutoDL 画面规格

AutoDL 视频模型的上游模型 ID 原样透传为 ComfyUI 工作流 ID，上线新工作流无需更新插件。“能力与参数 → 画面规格”多选完整分辨率并设置默认值：插件 v2.4.0 已声明的工作流使用各自预设，其他工作流默认提供 480p竖、768p竖、960p竖、480p横、768p横、960p横（默认 768p竖），也可直接输入上游支持的其他标签。未声明工作流的请求把全部参考图编号为 `ref_image_N`、参考音频编号为 `ref_audio_N`，数量由模型能力中的参考限制控制。AutoDL 通过完整分辨率标签控制横、竖、方形，不显示独立比例控件。

后台保存、用户模型目录、画布参数归一化、计费规格选择、服务端校验及插件请求使用同一套所选规格。至少选一项，默认值必须属于所选列表。价格档可保留全部插件预设的价格，但不会扩大实际允许生成的分辨率范围。

## 画布媒体产出模型

图片、视频、音频在生成成功并写入节点后，会冻结当时提交的产出模型。提示词面板里的模型下拉仍是下一次要用的选用模型，改下拉不会改掉已经生成的内容。画布外观中的「媒体信息」打开后，有内容的媒体节点在左下角显示产出模型；图片右下角继续显示尺寸和体积。上传、粘贴、截取、合并、提取音频和本地加工不记录产出模型。本次改动之前的节点不回填。分享页和版本预览画布不显示这块信息。

## 画布媒体版本

图片、视频、音频节点在原位重新生成或替换文件时，会把旧媒体保留为节点内的历史版本（V1、V2…，每个节点保留最近 30 个）。单张重新生成已有生成结果时直接在原节点产出新版本，节点 ID 和连线不变；多张输出、上传素材和「创建参数变体」仍新建节点。生成失败时旧版本保留在历史中，可以切回。

有可回看的版本时，节点右上角显示「V3/4」角标，浮动工具条出现「版本 N」按钮，右键菜单「版本历史」可用；只有一个版本时右键项置灰，工具条和角标不显示。版本面板底部的缩略图条支持悬停预览、方向键浏览、Enter 或双击切换；图片可开启「对比当前」，拖动分隔线比较。右侧显示模型、比例与分辨率、耗时、参考素材数量和提示词，并标出与当前版本不同的提示词。切换只替换媒体字段，提示词和下一次生成参数不变；锁定或生成中的节点不能切换。另可把任一版本另存为新节点，或删除非当前版本。

版本记录在画布文档的 `metadata.mediaVersions`，媒体字段沿用 `storageKey` / `content` 等原字段名，后端资源引用扫描和本地缓存清理都会把历史版本的资源视为在用。复制节点不带版本历史。只读分享页不提供版本入口。

## 画布资产视图

画布顶栏正中提供「画布 / 资产」切换（窄屏在画布菜单里切换），视图写在 URL 的 `?view=assets` 上，刷新后保持。资产视图把当前画布里有内容的节点整理成「类型 → 资产 → 版本」目录：类型固定为文本、Markdown、图片、视频、音频；上传的 `.md` 文本归入 Markdown。同一 `versionOfNodeId` 的 A/B 节点合并为一个资产，批量生成和拆层的子图归到批次下，节点内的 V1/V2 历史展开为版本，主版本带星标。

点选分类显示缩略图网格，点选资产或版本显示预览、尺寸、时长、模型和提示词，可重命名、下载、设为主版本或「在画布中定位」（切回画布并选中、聚焦该节点）。目录完全由画布节点派生，不新增数据表或接口；重命名和设为主版本走画布原有写路径。资产视图打开时画布快捷键暂停，左侧工作区轨道仍可用，原工作区的「资产」页签改名为「素材库」。实现见 `web/src/lib/canvas/canvas-asset-catalog.ts`、`web/src/components/canvas/canvas-asset-view.tsx`。

## 画布 Agent 名称、文案与形象

## 大规模画布保存

单次变更多于 500 条 operations 时，客户端按原顺序分批提交，并在每批发出前保存可恢复的请求。全部批次确认后才完成整份画布保存；中途失败保留未确认内容和未提交操作，响应丢失则用原请求 ID 与正文重放。每批是独立事务，部分批次成功不等于整份画布已经保存。协议边界见 [HTTP API](/docs/backend/http-api)。

## 支付订单与对账导出

管理员在 `/admin/payments` 可按关键词、状态、渠道和创建/支付/入账日期筛选订单，并导出全部匹配记录的 CSV。对账支持按渠道、执行状态和账单日期导出每日汇总；单次对账明细支持按结果或“仅异常”导出。单次最多 10000 行，超限明确提示，不静默截断。文件使用中文表头和北京时间，保留完整订单号、精确金额/积分及失败原因。导出不触发查单或积分补发；对账运行中不能导出明细。具体字段和参数见 [HTTP API 合同](../backend/http-api)。

## 首页常驻滚动通知

工作台首页顶部可展示运营配置的常驻滚动通知。管理员在「用户与运营 → 常驻通知」维护标题、类型（公告 / 活动 / 更新 / 警告）、配色与动效、按钮文案、生效窗口、倒计时和跳转链接；标题支持分段样式和光标处插入 emoji。通知条为深色底，一圈大光环在条上缓慢公转，亮带来回流过，经过文字时自动减弱、两端保持鲜亮；深色主题下底边挂一条颗粒带，叠在下方侧栏与内容区上、颗粒之间露出下层界面本身的颜色，外形（方格 / 圆点 / 菱形 / 平滑）与波纹（平直 / 锯齿 / 涟漪）可在后台「底边样式」切换，浅色主题保持直边；配色默认跟随类型，也可以选推荐配色或自选底色、光晕色（按钮文字色自动匹配），并可让光晕静止；有链接时右侧显示白色行动按钮（留空按类型取默认文案），开启倒计时后在标题前显示距结束时间的数字块；放不下的长标题左右往返滚动。

公开接口 `GET /api/banner-announcements` 只返回当前生效条目，并带服务端时间与下一次变化时间：前台按服务端时钟计算倒计时，到结束时间立即下线，预约通知到开始时间立即上线。多条通知轮播时悬停或聚焦暂停，右侧圆点可切换；用户关闭后按「条目 + 更新时间」本地记录，后台新增或重新编辑的通知会再次出现。

## 云端 Agent（写入与生成仍待真实环境验收）

浮窗支持移动、调整大小和浏览器偏好恢复；在画布里可以停靠到右侧，画布让出相同宽度不被遮挡，停靠宽度可拖动左边缘调整（视口窄于 960px 时自动回到浮窗）。面板使用实色背景，不做毛玻璃。后端支持逐轮对话、可信历史、取消、Skills 快照、画布摘要/精读、审批后的画布写入及媒体生成。运行中可插话（下一步生效，不打断正在飞的调用）；多步任务可用 `plan_update` 维护待办清单并在输入框上方展示，未完成项会催办；`request_approval` 下首次 ≥2 项清单会先确认，`auto` 直接建立。`ask_user` 在输入框上方显示可点击的选项卡片并结束本轮；Agent 回复末尾列出的编号选项也会变成卡片，点一下就作为回复发送，不用再手动输入编号。每个用户有一份长期记忆文件（关于用户 / 工作笔记，默认 5000 字）：Agent 在用户纠正它、说明偏好或要求记住时用 `memory_update` 自己整理，默认立即生效，每次修改都能在聊天卡片或「Agent 设置 → 个人记忆」里撤销，也可以改成需确认或关闭。记忆快照只作为本轮的数据消息注入，不进系统提示；管理员可按用户只读查看。只读模式不能写记忆。用户已安装的技能编成预算受限的目录（最多占输入预算 5%），Agent 开始任务前会自己对照目录找合适的技能，每个技能可设为“自动”或“仅手动”；已装技能都不适用时，Agent 会推荐技能市场里的技能，由用户点安装。技能库和 Agent 设置提供按行业安装推荐技能的入口。终态旧轮次按其冻结合同保留为不可变历史，新消息使用当前合同创建新轮，不篡改父运行；旧合同下仍活动或待审批的运行不会被新版服务恢复执行。生成由预算和独立审批控制，画布写入使用内容快照哈希；未开放外部 MCP，联网只通过服务端的 `web_search` / `web_fetch`：平台开启联网搜索且用户没关时可以搜索（与首页共用开关、次数和计费），读取公开网页总是可用。系统行为策略以版本化资源发布，用户/项目/画布可编辑常驻偏好；偏好正文固定在运行快照并按层只读，不整段塞入 system prompt，也不能提权或跳过审批。节点创建、更新字段、摘要投影和连线限制来自服务端能力 registry；能力卡同时描述用途、适用场景、不适用场景、维护代价和可用动作，由 Agent 结合镜头数量、连续性、逐镜审查和交接需求自主选择，不强制所有任务使用分镜。分镜脚本支持结构化创建、分页读取及按真实行 ID 追加、修改和删除；普通文本和 Markdown 不会被宣称为具备镜头级维护能力的分镜表。图片、视频和音频节点可安全修改标题与下一版提示词草稿，既有媒体、已提交提示词和任务状态不会被草稿编辑覆盖；媒体模型按生成模式和真实参考节点从统一目录筛选。审批和执行记录明确展示目标节点、类型、修改字段、名称变化及连线两端，前端不再依靠内部 ID 猜测；这些预览不替代服务端归属、快照、Capability、锁、预算与调用哈希校验。真实模型计费与浏览器联调仍待验收。

云端画布 Agent 已分离行为策略、用户目标、参考事实和运行状态。续聊保留已送达插话，不再继承代码预设的创作自由；旧待办只作上下文，可移除取消项，催办不会强制工具调用或无限重复。提示词来源与发布约束见[画布 Agent 提示词与用户意图](/docs/backend/agent-prompt-policy)，真实模型行为仍待场景验收。

同账号设备可在同一画布接续同一段 Agent 对话，恢复完整轮次和事件，并同步运行进度及审批结果。未发送草稿、未确认提交和下一轮设置保留在本机；手动选择的旧历史不会被其他会话抢占。原有画布互斥及幂等提交保护保留，旧父轮不能另开分支。

图片生成审批支持连续切换宽高比、分辨率和质量，同一次点击产生的多个参数更新会累积；扩展参数中的旧规格不再覆盖当前选项，提交时使用最终展示的规格。

## 3D 预演台（持续完善，待用户验收）

预演台从画布镜头节点打开，统一提供摆场、姿态、动画、摄影机与时间轴。镜头焦段和画幅共同决定取景，机位视图显示安全框；画幅在视口工具条选择，支持自适应（跟随视口）、2.39:1、21:9、16:9、4:3、1:1、3:4、9:16。添加角色时，每种体型用标准人偶缩略图展示，按同一机位渲染，身高可直接比较。构图截图、白模视频、深度图与深度视频使用同一镜头摄影机输出。深度产物回写为独立画布节点，不自动作为普通图片参考提交给模型。

工作台内可下载当前模式的镜头截图、录制镜头画面，或通过浏览器共享选择器录制含面板与操作过程的窗口。实时镜头录制要求标签页保持可见。第二屏监看用独立窗口显示镜头画面，支持全屏；自动定位外接屏依赖浏览器授权，也可以手动拖动。工具条与帮助面板提供[预演台快捷键](/docs/canvas/canvas-shortcuts)。

画布 Agent 使用 `previs_scene_read` 读取摘要，使用 `previs_scene_create`、`previs_apply_patch` 经审批创建和修改场景。路径操作生成真实变换关键帧，设置路径替换对象原变换轨道，清除路径清空该轨道；焦段修改同步取景。`previs_preview` 仍依赖已打开的浏览器工作台执行，尚无完成回执。

演员使用本地打包的 CC0 光滑人体模型（Quaternius Universal Animation Library 的 Mannequin，许可见 `web/public/previs/LICENSE-mannequin.txt`），姿势与动作写在规范骨架上再重定向到蒙皮，存档与模型无关。落地规则在前端提交与 Agent 写入两侧一致：演员高度锁为地面，道具可抬高但底面不得低于地面，打开旧场景时自动拉回地下对象并提示。检查器按变换、体型、外观、姿态、动作分组，道具库为按比例缩略图卡片并可折叠。程序化布景、排戏和离线逐帧编码仍属后续工作。

## 技能库个人分类与画布 Agent 筛选

技能库保留原有头部和技能广场共享分类；在“我的技能 / 我创建的”视图增加左侧个人技能库分类及技能数量。用户可为已加入或自建技能创建、分配个人分类；管理员也可创建对所有用户可见、可选、可用于筛选的分类。个人分类仅影响当前用户的技能库和画布 Agent，不改动技能广场共享分类。删除分类只解除相关归类，技能仍保留。画布 Agent 的“我的技能 / 已启用”列表可按个人或平台技能库分类快速筛选，市场页仍按共享分类浏览。

## 图层拆分尺寸适配

AI 图层拆分保留现有弹窗和模型选择方式。固定规格模型可自动适配常见非标准比例照片：参考图等比缩放与补边，结果去除适配边带并还原为原图画布，框选坐标同步换算。模型工作尺寸按当前分辨率档选择，不自动升档或切换渠道。任务保存尺寸变换信息，逐层提取、去背景、刷新恢复与单层重试共享还原逻辑；部分失败保留成功图层，刷新不会续发未提交的付费调用。极端长图、空图或明显改变工作画幅的结果继续拒绝。

## 画布 operations 同步与本地恢复

画布内容按字段和对象生成 operations，节点、连线和顶层业务字段分别提交；平移、缩放等 viewport 只保存在本地。每次请求携带唯一 `mutationId` 和可选基线版本，服务端在同一事务中校验对象存在性、字段基线、资源归属并保存回执。可选顶层字段不存在时用 JSON `null` 表示，避免 `undefined` 被序列化为缺失属性。相同请求安全重放，响应丢失、断网、刷新或服务端暂时不可用时，浏览器保留已确认基线与未确认请求，后台使用原 ID 和原 payload 自动继续处理。结构化配额只聚合当前用户素材与画布数据，不扫描任务和 API 日志大字段，容量上限与事务语义不变。

不同字段的并发修改可以合并；同一字段或同一对象的基线不一致会返回冲突，当前本地修改继续保留。删除后的迟到节点、连线或媒体更新不会重新创建对象，只有显式新增 operation 可以创建实体。界面只显示同步状态，不提供版本记录、加载云端版、覆盖云端或手动恢复入口。

此合同不提供多人实时协同；它保证局部变更、幂等重放和删除保护，避免旧缓存静默覆盖新内容。内部历史表仍用于资源完整性维护和审计，不作为用户编辑入口。

相关实现见后端 [画布 operations 同步](/docs/backend/canvas-operations-sync)、`web/src/services/user-data-sync.ts`、`web/src/services/api/user-data.ts` 和 `web/src/pages/canvas/canvas-sync-status.tsx`。

## 画布智能引用

节点提示词面板提供“智能引用”入口，支持 AutoLink 开关和“一键引用全文”。输入已连接素材的名称、标签或素材栏序号后，按 Tab 或点击光标旁的候选项插入引用；全文引用会批量转换匹配到的指代，没有可转换内容时按钮禁用。

匹配仅覆盖当前已连接且激活的画布素材，跳过技能、素材库条目、重名歧义和已有引用。支持 `图1`、`图片1`、`image1`、`image 1` 及独立序号；普通数字文本如“约2秒”保持原样。AutoLink 默认在节点面板开启，开关为面板临时状态。

## 批量创作表

批量创作表每行是一项任务，每个参考图格子绑定一张图片；同一行可通过多个参考图列使用多张图。点击格子可选择画布图片或上传，也可把图片连线接到指定格子。已有图片替换前确认，清除格子保留源图片节点；保留列排序和表内跨行、跨列交换。

左侧 1、2 等列端口直接生效：一张图片供该列各行共用，多张图片按连接顺序分配。单格更换或清空后成为独立配置，不被列变化覆盖；“按列填充”可在确认后恢复已连接列的统一配置。列同步只更新参考图，不重建任务行；AI 文本列表创建的表格保留独立行、动态文本列和原有生成流程，未开放普通文本节点直接连入批量表。

顶栏、普通表头、行号和非交互留白均可拖动整表；输入框、参考格、按钮、列排序和原生滚动条保留各自操作。表内支持文字拖选、内部滚动、底部添加和在指定行下方插入。放大编辑与行内编辑使用同一份提示词。全局提示词非空时统一覆盖各行的生效提示词，清空后恢复各行原文；界面显示实际生效来源，Agent 的 `set_global_prompt` 和 `generationPreview` 沿用此规则。“批量换装”和“创意生图”的预设保留。

任务入队时保存提示词与参考资源快照，排队期间修改或旋转源图不会改变已提交的输入；旧结果在输入变化后标记“输入已变更”，由用户决定是否重新生成。超过 20 行时仅挂载可见行、附近行及正在编辑的行，减少大表 DOM 和重绘开销。最终浏览器联调与性能验收见[待测试](/docs/progress/pending-test)。

## 图片尺寸与方向

图片节点按原图比例确定显示尺寸，可用角点调整大小或打开图片预览。普通滚轮保留原画布操作；单选一张未锁定的普通图片后，按住 Ctrl 滚轮可等比例改变其显示尺寸，鼠标移到画布空白处仍作用于选中图片。连续滚动合并为一次撤销和保存，不重采样图片或改变生成参数。编辑框、表格内部、多选、锁定、图层图片和只读页不进行这种尺寸调整；触控板捏合仍操作画布。

在原图工具中选择“向左转 90°”或“向右转 90°”，首次会保留原图、自动创建已经旋转的编辑副本，并连接和选中它。副本顶部保留左右转按钮，之后在同一副本上继续旋转或恢复创建时的方向；也可提前用“创建编辑副本”。

旋转生成实际图片资源，副本的下载和新提交引用使用校正后的方向；原图及其既有引用保持原样。引用编辑副本的格子会随副本更新，已入队任务仍使用提交时的快照。原方向与已生成方向保留，重复切换可复用资源。锁定、只读或尚在上传的图片不能旋转；此入口不提供任意角度或镜像操作。节点工具组菜单使用统一宽高限制，长说明单行显示并保留完整悬停说明。

工具栏根据侧栏以外的实际可用宽度收起次要操作；节点编辑面板根据剩余高度调整位置或内部滚动，避免遮住底部控件。未选择显示模式时，721–1023px 的窗口默认使用专注模式，手机（≤720px）默认使用精简的普通布局（见「手机端」）；用户明确进入或退出后，窗口变化与刷新保留该选择。

## 提示词放大编辑

图片和视频节点的提示词面板支持放大编辑：窗口默认约 `min(1200px, 92vw)`，编辑区最小高度 200px，右下角可对角拖拽，方向键可微调。切换节点后尺寸恢复默认，节点上的紧凑面板外观不变。

## 画布抓手与框选

画布底部主工具栏用一个胶囊开关切换「区域选择」和「抓手工具」。默认是区域选择，空白处拖动框选节点；切到抓手后拖动平移画布。按住空格或中键仍可临时平移，不改变当前工具。

框选多个节点后，悬浮栏默认提供对齐、等距、创建分镜组和批量连接。右键选区或画布空白处可「自适应整理画布」，按当前相对布局加大边距，而不是重排成宫格或媒体泳道。

## 完整 AI 拆图工作流

图片节点的 AI 拆图可先用支持视觉输入的文本模型规划图层，再选择专用拆图模型，或用普通图片模型分别重建背景与前景。规划发送经过资源归属校验的实际像素；规划结果校验图层数量、区域与提示词，失败保留可修正的错误。

生成结果组成同尺寸图层组，支持展开、显隐、合成预览、复制、删除、失败重试和刷新恢复。前景可按需去背景，Image Tools 强制输出 PNG；透明内容可按有效区域裁切并另存为独立素材。派生图片使用独立资源与素材标识，避免覆盖原图或其他图层。

规划、生图及可选去背景沿用已有任务与计费；本地合成、显隐和素材裁切不调用生成模型。普通生图是语义重建，不能保证与原图逐像素一致。图层数、像素与输出比例受前端限制，供应商失败如实显示。

## 图片节点多角度、宫格切分与多选框

图片节点「多角度」使用贴在节点下方的 3D 编辑器（天空盒/摄像头、常用角度、方向箭头），拖动节点或平移画布时面板跟着走。宫格切分放在「图片工具」菜单的「拆分与标记」里，提供 4/9/16/25 预设和 5×5 自定义点选；自定义面板留在菜单内，切分后的子图按网格排开。框选多张图后拖动，虚线选框跟随被选节点。

图片工具「AI 图层拆分」使用简洁弹窗：原图可拖动框选重点区域，右侧只保留补充要求、视觉规划模型与图层拆分模型。点击「开始拆分」即自动先规划后拆图，其他参数采用默认值。视觉规划选择器按参考图片输入能力筛选，保留 `image-tools-layer-decomposition` 专用协议及可编辑参考图的普通图片模型；不根据模型名称猜测能力。无法识图、规划请求失败或返回无效计划时显示具体错误，不提交后续图片任务。

开始后画布立即显示「拆解规划中」，有效规划完成后显示「拆解中，共 N 张图」。同一秒表从规划开始计时，切换阶段不会归零；重复点击不会重复提交。刷新中断规划等待后提示重新发起，不自动继续收费拆图。

规划为每层分别生成独立提示词和透明度参数：背景仅描述保留环境、移除目标及遮挡修补，明确不透明；前景仅描述本层保留对象，明确透明。执行不再拼入用户总体要求或其他层描述，模型、尺寸、质量和单张输出仍沿用现有配置。缺失参数或透明度与角色冲突时，在提交图片任务前停止；保存本层执行提示词及配置，手动重新生成仍使用本层参数。弹窗、进度文案、计时及图层展示保持不变；提示隔离不保证上游模型一定返回符合要求的 alpha。

规划按结构返回提取方式：完整矩形、圆角面板或椭圆区域可直接复制原图像素，输出仍为原图完整画布，区域外是真实透明，不居中、缩放或重画。选区内全部内容保留，不能以矩形裁取冒充不规则主体抠图；复杂轮廓、文字字形和遮挡补全继续使用模型。无效显式区域阻断提交并提醒重新规划，不自动回退付费生成。

默认只收纳一组背景与前景，原位图层保留原图画布用于叠放与合成，组默认折叠；背景移除已拆内容并修补，前景默认参与合成。完成后可在「管理图层」手动另存独立素材（免费），仅裁去外部透明留白，保留完整场景内部背景、圆角和柔边，供下载、编辑和再次拆分。独立素材使用各自尺寸，不替换合成子层；预览框限制在 720×520 内，极宽文字以原比例放入框内，创建及图片解码使用同一规则，文件像素不缩放。底板失败时保留成功前景和错误原因，不自动重试。前景不补画原图未展示内容；背景仅修补已拆前景遮挡位置，不扩展画幅。

识图按美工可复用的编辑单元规划，完整面板优先保留内部场景；边界不确定时保留原图提取方式，区域无效则停止，不因此付费重画。规则矩形/圆角边界按邻近像素对比免费校准；校准是保守建议，不保证精确分割。不按题材、固定格数或图片名称选择规则。

前置识图模型给出图片结构、编辑目标和提取策略，按完整场景/对象/文字/装饰/组件规划。默认背景与前景分离，必要前景从背景移除并修补；完整 scene 分类不允许自动重画或内部去背景，复杂主体使用模型轮廓提取。超过八层先按完整组件分组，再按需继续拆分；分类不代替几何及尺寸校验。透明度判断用于既有去背景流程，最终显示不以透明度不达标拦截有效结果。节点标题仅保留素材名称，完整描述与坐标保留在计划中。

当所有需移除的对象均有明确原图区域时，底图修补只采用这些区域内的模型结果，区域外保持原图；混合不规则对象时仍使用模型完整底图。修补质量和模型轮廓仍需验收。原图提取不调用图片模型，只有模型层及必要的去背景按实际调用计费；各层并发处理，原图层不等待模型底图。保存原始资源与区域供刷新后手动重提取，原图层重试仍为零图片调用，缺少资源明确停止。视觉规划的区域边界可能近似，结果应与原图核对；原图提取保证所选区域内的原始像素，不保证模型估计的边界准确，也不补全被遮挡内容。

识图默认使用最长边 1000 像素的等比例兼容预览，可切换原图以读取密集文字和小细节；只影响文本规划输入，拆层继续使用完整原图。规划提示将海报中的多张照片按独立场景处理，优先整张照片/卡片成层，并要求保留内部不透明场景、仅面板外透明；普通生成模型仍可能误作主体抠图或重排，不能把提示要求当成质量保证。坐标仅为可选位置提示：声明像素单位并匹配实际输入尺寸时统一换算；无效坐标不拒绝整份语义计划，省略该提示并显示核对警告，不猜单位或静默裁剪。提取及去背景均明确声明换算后的 0–1000 坐标基准，不作为新画布尺寸。点击「读取最近可用规划」可在同画布最近 50 条任务中恢复同源图的已有有效结果，不产生新模型调用；旧记录缺少资源标识时明确提示核对图片和要求。

默认「自动拆分」根据照片、商品、插画或海报的实际结构选择 2–8 层，不固定题材或强制两层；详细拆分可增加文字与细节层。逐层模式可逐项选择是否从底图移除对象：主要编辑对象通常移除并补全遮挡，备用细节可仍保留在底图，透明副本供叠加或备用；移动或替换重复细节前需修补底图中的原对象。不能识图、无可拆内容或缺少现有底图时，规划明确失败，不虚构对象或底图。规划仍要求不透明背景及透明前景，背景不执行去背景；前景仍按至少 0.1% 的像素为 alpha=0 判断是否需要既有去背景步骤。最终背景含透明/半透明、前景仍不透明均可显示和合成，保留实际 alpha；完全透明空图、损坏资源和尺寸异常仍停止。错误比例提示原图与实际尺寸，不通过拉伸掩盖构图变化。

所有逐层任务结束后，已验收的结果可以形成部分合成并收纳在同一组，明确显示完成层数和缺失背景，失败层仍可展开检查。手动重试只调用选中的失败层，不重跑成功层；中断后需要去背景时，手动恢复一次只调用一个阶段。新成功层加入合成时保留已有可见性、顺序与展开状态。刷新不会自动继续收费。

背景与其他对象同时提交提取，图层顺序仍按计划从底到顶排列，不受完成先后影响。可另外选择去背景模型：前景提取结果缺少真实透明区域时，以该层结果为参考执行一次去背景；已经透明则跳过。本层去背景不等待背景或其他层，一层失败不阻断其他已提交图层，组等待所有结果后汇总失败；不自动付费重试。规划、提取及去背景分别计费，N 层最多 N 次提取和 N−1 次去背景；刷新不续发尚未提交的收费步骤。实际执行受后台 Worker、渠道及上游并发额度限制，真实排队状态不会伪装成运行。

读取源图实际像素后锁定原图画布，各层和合成图统一保存为原图宽高及比例。模型请求优先使用已声明的自定义比例或相符预设，允许 auto 的模型可按参考图返回；无法支持时明确报错，不回退到默认方图。原始输出最多接受 1% 的尺寸取整比例差并归一化到原图画布，明显比例变化直接拒绝；这不是通过 UI 拉伸来冒充正确结果。普通生成模型仍不保证精确坐标、语义分割与原图像素还原。

专用协议输出按资源实际像素验证：至少两张同尺寸图片，拒绝单张拼版、全透明空层、损坏资源和尺寸不一致的结果；不因透明度不达标拦截最终显示或合成。唯一不透明候选仍沿用置底规则，多张候选保留返回顺序。逐层结果从开始即收纳在同一组、默认折叠，全部结束后对已通过层显示完整或部分 PNG 合成预览；可展开、下载、复制和独立编辑，调整合成顺序及可见性。画布展开位置不参与合成，隐藏、排序及重新合成都不请求模型。框选只作为提示；模型的分割语义与还原质量仍需实际验收。

画布内图层和合成预览与普通去背景图片采用同样的透明显示，透明区域直接透出画布背景，不额外绘制棋盘格；PNG 保留产出实际 alpha，不强制修复透明度。仅放宽最终显示与合成验收，规划、请求参数、去背景触发及处理次数、界面、阶段、计时和重试逻辑保持不变。

## 系统渠道排序与前台别名

系统渠道模型选择器直接读取渠道下的模型列表：一级跨渠道按“模型展示名”分组并显示原色 Logo，二级显示该模型的“渠道展示名”及规格售价；留空使用所属渠道名称。模型调用标识不必相同，也不反查逻辑模型。系统渠道的“前台名称”已移除。调用保留用户选中的具体渠道，收起后显示“模型 · 渠道”，不因另一渠道更便宜而自动切换。图标优先使用图标库的原色版本，缺少彩色版本时使用单色版本；缺少配置时显示通用图标，不猜测产品品牌。

渠道模型价格档支持管理员单独配置积分成本价；后台请求记录分列显示预授权、实收和成本金额，只有已结算订单才显示实收。成本按下单快照计算，不追随之后改价；普通用户页面及接口不返回成本字段。

系统渠道模型列表按规格显示成本价 / 销售价及利润率；文本输入、输出、缓存 Token 分开呈现。勾选多个模型可统一调价：弹窗一行一个模型，展示模型名、渠道展示名（上游 ID）、规格、成本与可编辑售价，多规格在模型行内纵向对齐。输入目标利润率并选择保留 0–6 位小数（默认 2 位），按 `成本 / (1 − 利润率)` 四舍五入实时计算；也可点击「重新计算」覆盖手动值，再逐项修改。保存最终输入售价，服务端校验价格与版本并原子保存，不改变成本或启停状态。

后台系统渠道通过“设置排序”、模型管理通过“自定义排序”打开完整列表。支持搜索选择条目后输入目标位置，也可拖动、上移和下移；列表显示从 1 开始的位置，点击“保存排序”统一生效，取消不会修改线上顺序。渠道行的“更多”菜单支持复制渠道，复制会生成独立的渠道、模型和价格档，并保留原连接配置与凭证。排序不受筛选及分页影响；并发修改会提示重新加载，避免覆盖其他管理员的调整。系统渠道模式下，用户端模型选择器沿用同一渠道及模型顺序。模型排序独立保存，不改变价格、能力版本或启用状态。

系统渠道可设置可选的前台别名；为空时显示渠道名，设置后公开目录和用户会话只返回别名，后台仍保留原名。别名最长 80 字，支持后台搜索。前台模型目录模式保留其独立配置。

注册默认每 IP 每小时允许 30 次注册请求、60 次验证码请求，单邮箱每小时另限 10 次且发送后间隔 60 秒。失败尝试也占请求额度，达到上限后的拒绝不会继续增加计数或延长窗口；限流响应携带真实剩余等待时间，注册页面显示倒计时并防止重复提交。已保存的运行策略仍需管理员按实际共用网络规模调整，不随默认值升级自动覆盖。

定时闲置资源清理与后台手动删除共同保护外观配置引用的浅色 Logo、深色 Logo、登录视频及封面；即使资源超过闲置期限也不会删除，外观配置无法读取时停止相关清理。

## 章节资产提取与任务浏览

画布视频支持鼠标悬停 350ms 后静音预览前 3 秒，不循环；全局仅一个悬停解码器，离开或操作画布立即停止并恢复封面。手动播放优先，系统开启减弱动态效果时不自动预览。

剧情章节支持一次提取角色、场景与道具，分别写入角色、环境和道具待确认资产。输出必须包含三类数组；无人章节可以只产生场景或道具，不把缺失字段当作提取成功。

场景和道具确认后保留描述与生图提示词，尚未出图时显示「待生成图片」。可使用项目画风生成参考图，或绑定素材库中已有图片；提取和确认不会自动发起收费生图。图片绑定创建新资产版本，已有镜头、画布继续引用原图片。生成任务的成功状态与图片绑定共同提交，取消或失去租约的任务不能换图；晚到图片不覆盖较新资产版本，原生成结果仍可在任务中心恢复使用。

任务详情只读取任务与日志，不因打开详情写入画布。视频任务列表和网格优先展示已有封面；没有封面时，在进入视口后提取首帧缩略图。后台请求明细默认仅显示请求，可切换仅下载或全部明细，导出沿用当前筛选条件。

## 站点及外观

管理员可以在“系统配置 → 站点及外观”统一管理品牌识别、创作首页、登录页、SEO、首页收尾与备案、皮肤主题。品牌识别包括站点名、英文品牌标识、浅色与深色 Logo 和 Logo 外框；创作首页分「生成」「画布」两列，分别配置 `/create` 和 `/create?mode=canvas` 顶部的标题与副标题，各带预览；登录页包括主标题、说明、品牌视频和可选封面。Logo 可以只上传任意一套并自动复用，也可以分别适配浅色与深色界面；关闭外框后 Logo 会在原导航占位内等比放大。

前端入口在加载 React 应用之前先读取 `GET /api/public/appearance`。初始 HTML 不包含内置品牌名、Logo 或默认 favicon；只有公开配置成功或明确回退到内置外观后才渲染应用，避免自定义品牌访问时先闪现“影策”。自定义视频未设置封面时保持纯色背景直至视频首帧就绪，不复用内置视频封面。

浅色 Logo、深色 Logo、视频和封面通过后台专用上传接口进入现有资源存储，并由稳定的公开 slot URL 读取；公开响应不暴露资源 ID。正在使用的外观资源会阻止管理员从资源管理页直接删除。英文品牌标识可作为对象存储路径前缀建议，但不会自动覆盖已经保存的前缀或改写历史资源。“恢复影策默认”会恢复内置品牌值、SEO/页脚默认值、经典皮肤和默认 Logo 外框，同时保留已经上传的素材文件。

SEO 标题、描述、可选关键词会投影到浏览器 metadata、Open Graph、Twitter Card 与 canonical；版权信息在公共登录场景页脚显示。ICP备案默认关闭，启用后必须填写备案号，并链接至工信部备案系统。注册验证码与密码重置邮件的标题、正文和继承型发件人名称都会使用当前站点名。

皮肤主题以语义令牌集中管理浅色/深色背景、文字、表面、边界、主色、控件状态、hover/active/focus、图标、圆角、尺寸、动效和阴影。默认“经典黑白”不可修改或删除；“青瓷工作室”“暖柿纸境”“霓光紫境”作为重新校色的可编辑初始数据。每套主题还可独立设置警告色、危险操作常态/悬停/按下/前景，以及开关开/关轨道、悬停和滑块色。管理员可从经典或当前主题完整复制、新建、改名、编辑、启用和删除自定义主题；页面只消费语义变量，不按皮肤 ID 分叉业务组件。

主题卡顶部会按语义使用频次展示该主题浅色与深色令牌的全部去重颜色，宽度不足时保留高频色并截断尾部。颜色编辑器只在直接点击色块时打开系统取色器，点击名称、说明或 HEX 输入不会误触。

## AI 提示词优化器

提示词优化器是一个内置 AI 能力插件，用于把模糊的生图或生视频想法整理成可以直接使用的提示词。它复用宿主已经配置的文本模型和渠道，不在浏览器中保存或拼接第三方密钥。

### 使用入口

- 创作页 `/create` 的提示词输入框中，点击“优化”。
- 画布中的图片或视频节点提示词编辑器中，点击“优化”。

面板使用紧凑的聊天式交互，跟随当前输入框定位，支持拖动、边缘调整尺寸和窗口尺寸变化。打开与关闭不使用延迟动效，避免遮挡画布或让用户误以为请求卡住。

### 优化方式

| 方式           | 用途                                                           |
| -------------- | -------------------------------------------------------------- |
| 扩展想法       | 从模糊想法补齐主体、场景、构图、光线、镜头等可执行细节。       |
| 精修已有提示词 | 尽量保留原意，只修正表达并补充必要细节。                       |
| 强化风格       | 保留主体和动作，强化色彩、材质、光影与指定风格。               |
| 适配模型       | 按当前生成模型和协议调整提示词结构，避免使用未确认的参数语法。 |
| 结合参考       | 使用已连接的图片或文本补充外观、一致性、构图和关联关系。       |

面板底部可以单独选择优化所使用的文本模型；目标生成模型仍取当前图片或视频生成配置。两者职责不同：前者负责整理提示词，后者负责最终生成内容。

### 结果与安全边界

- 优化结果以结构化内容返回，包含正向提示词、规避项、修改说明、假设和可选备选版本。
- 结果可以继续编辑；只有点击“采用”才会回填当前输入框，并自动关闭面板。
- 请求支持流式反馈、取消和错误提示，不会在优化失败时覆盖原提示词。
- 参考素材只提交当前已连接且符合类型的内容；插件不自行访问素材库或后端密钥。

### 相关实现

- `web/src/lib/plugins/builtin/prompt-optimizer.ts`：插件清单、优化方式和模型适配策略。
- `web/src/components/canvas/canvas-prompt-optimizer-drawer.tsx`：聊天面板、拖动缩放和结果采用交互。
- `web/src/services/plugin-host.ts`：将插件文本请求接入宿主现有模型渠道。

## 画布同步与离线恢复

## 画布外观

底部工具栏的“画布外观”面板支持浅色、深色、自定义三种主题，以及点阵、线稿、空白三种网格。浅色画布使用比白色节点更沉的中性雾灰背景，深色画布使用比原深色节点更亮的中性灰背景，让画布底层与内容表面保持稳定区分，同时避免蓝灰背景与黑色工具浮层产生色温割裂。

自定义主题会继承用户进入前的浅色或深色基础界面，并允许在“浅色界面”和“深色界面”之间切换。界面样式复用原项目整套节点、工具浮层、文字、边框和交互状态，不开放这些元素的任意改色；切换界面样式不会覆盖已经选择的画布背景和网格颜色。

自定义主题还允许调整画布背景色、背景明亮度、网格颜色和网格强度。颜色输入支持三位或六位 HEX，可带或不带 `#`；形成合法色码后实时写入当前画布，编辑过程中不会被父级状态覆盖，关闭外观面板也不会撤销。选择新的画布背景色时明亮度自动归零，确保画布首先精确显示输入色；之后仍可沿 OKLCH 亮度轴单独调整。不提供背景透明度，避免画布底色与底层颜色混合后产生偏色。“网格强度”使用 `0%` 最淡、`100%` 最明显的方向，避免“透明度”命名歧义。

自定义外观可以应用到当前画布，也可以保存为当前浏览器、当前账号 scope 下的新建画布默认值。当前画布外观沿用画布项目的既有持久化和同步流程；浏览器默认值不跨设备同步。

## 积分充值支付插件

## 剪辑成片（时间线编辑器）

“剪辑成片”是项目详情里的时间线编辑器入口（`/projects/:id/editor`），用于把已就绪的分镜视频编排成一段可播放、可导出的成片。它运行在浏览器本地时间线模型之上，通过后端任务队列完成语音转写与成片导出，编辑器本身不直接触碰原始媒体大文件。

### 使用入口

- 项目详情“制作流程 → 剪辑成片”步骤卡，或地址栏直接访问 `/projects/:id/editor`。
- 编辑器按项目隔离时间线状态；离开后再次进入会恢复该项目的编辑器快照。

### 当前能力

- **轨道与命令**：时间线支持添加、删除、拆分、移动、修剪片段等操作，全部通过统一命令状态机执行并进入 200 层历史记录，可撤销与重做；非法操作整批拒绝，不产生半应用状态。
- **预设面板**：左侧“添加”分类提供 8 个内置片段/字幕插件，按分类分组接入同一插槽注册链，第三方插件可与内置面板共存。
- **权限与执行边界**：命令执行遵循失败关闭（fail-closed）策略，`timeline.command` 权限与全局 `plugins.run` 权限分开控制；未授权插件或命令不会被执行或回显。
- **语音转写（字幕）**：对时间线音视频发起转写任务，转写进度沿任务 SSE 回流，完成后生成字幕轨。
- **成片导出（渲染）**：发起渲染任务，由服务端 ffmpeg 按渲染计划输出成片；渲染成功后在项目概览的“剪辑成片”步骤卡呈现“已输出 N 个成片”，并作为该步骤完成度的判定依据。
- **AI 编辑助手**：可以用自然语言描述剪辑意图，系统将其解析为受支持的命令序列；不超过 3 条命令时直接执行，多于 3 条先给出差异预览，确认后才批量执行。

### 运行环境要求

- 语音转写依赖本地 whisper.cpp 服务（`CANVAS_WHISPER_BASE_URL`），未配置时转写任务明确失败。
- 成片导出依赖服务端 ffmpeg（`CANVAS_FFMPEG_PATH`，留空时在 PATH 中查找）。

## 创作首页与灵感大厅

`/create` 是创作首页。空态首屏依次是大号标题与副标题（文案在后台「外观设置 → 创作首页」配置，保留换行）、「生成 | 画布」切换、宽大的提示词输入框（含创作类型菜单）和玩法条（头像、海报、商品图、表情包、故事分镜、短视频，点了只预填类型和提示词开头）。参考素材是提示词左边一摞斜放的小卡片（参考即梦）：鼠标停上去按顺序展开，最后是写着「参考图 / 参考素材」的虚线「+」，悬停时上浮放大，点开选「上传图片」或「从素材库选择」（上传的图片同时存进素材库，游客先登录）；输入框的默认提示会说明点「+」上传参考图、输入 @ 引用素材；卡片带提示词里的编号，展开后按住拖动调整顺序，拖到提示词的 @图片 上替换那一张。本机图片或对话里的生成结果拖到某张卡片上替换这一张，拖到「+」或输入框其他位置加到最后。触屏上卡片平铺在提示词上方一行。背景是动态方格加顶部柔光（参考 kunrouai.com）：方格缓慢向左上漂移，指针所在的格子亮起，移开后淡出；线取正文墨色、亮起的格子取主题强调色，明暗主题和皮肤各自成立。方格铺在整个工作区（顶栏透明，方格穿过顶栏，交界处没有色差），四周淡出；进页面只淡入，不再从标题处扩散光圈。往下滚到灵感大厅时方格淡出并停帧，「减少动态效果」下方格不动。对话中背景取最新一张结果图的缩略图，模糊后作底色，同样从透明顶栏下面铺起，顶栏和对话是同一块颜色。首屏下方直接是灵感大厅，不再显示最近画布，画布从侧栏「画布」进入。切到「画布」（`/create?mode=canvas`）时，标题和副标题换成「画布」面的文案（后台单独配置），输入框、玩法条、灵感大厅和素材来源换成「新建画布」加最近 3 张画布，下面是首页同一套「精选画布」。

灵感大厅合并到创作首页下方，不再提供独立灵感导航或 `/inspirations` 页面路由。类型与搜索常驻，来源、分类、收藏/隐藏和排序收拢在更多筛选中；默认每页 12 条。新建、编辑、隐藏/恢复、收藏与 JSON 导入导出继续保留，本地改动按账号 scope 持久化。使用灵感会关闭详情、回填首页提示词并返回输入区，不自动生成。

内置提示词统一提供中文正文，详情阅读、复制、编辑和回填创作使用同一份中文内容。已有中文来源直接采用中文版本，其余外文正文翻译后随静态目录发布；模型名、引用标记和模板参数保留原有用途。来源及原页链接显示遵循后台来源展示开关。

译文维护在 `web/scripts/data/inspiration-prompts-zh.json`，记录原文 SHA-256；导入脚本写入目录前校验原文版本，缺译会停止导入。

外部提示词由 `web/scripts/import-inspirations.mjs` 同步。`web/public/inspirations/*.json` 继续提供静态目录数据，灵感大厅进入可视区域附近后才按需加载全量目录，浏览器缓存与会话内缓存避免重复请求；封面保持稳定比例，加载失败显示占位内容。

## 画布外观预设

顶部保留浅色、深色和自定义三个入口。浅深切换恢复该色调最近的预设或微调；自定义仅展开、收起当前色调的设置，切换浅深不会改变展开状态。浅色提供经典浅灰、粉色、米色、浅绿，深色提供经典深色和柔和深灰；可调整明亮度、网格强度，并在“更多颜色”中修改背景和网格颜色。

单个画布自动保存预设快照、浅深色各自的微调和网格样式，工作台主题切换不覆盖已有画布。未设置新画布默认时，新建画布随工作台明暗选择经典预设，并默认使用线网格；旧画布缺省仍按点网格处理，已有显式颜色和参数继续读取。“设为新画布默认”仅作用于当前账号与本浏览器。外观及添加节点面板限制高度并允许内部滚动。
