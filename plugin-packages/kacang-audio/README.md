# 卡藏音乐

独立 `yingce.plugin/v2` 声明式协议插件，不包含可执行运行时。宿主管理渠道凭证、出站安全、审计、生成结果保存和恢复。

仅适配精确 API 模型 `suno`。选择 `kacang-suno` 协议后，“能力与参数”自动显示纯文本音乐、一个任务返回两首、关闭流式输出的默认合同。售价、成本和启用状态由管理员独立设置。

一手依据：[卡藏 Suno 文档](https://console.prompt-hubs.com/docs/model/suno)和[模型广场的 Suno API 参数表](https://console.prompt-hubs.com/pricing)。2026-10-10 的单次真实验收确认响应为聊天消息中的两个普通 Markdown 音频链接。文档页缺失参数区，模型详情页的四项正式参数优先于通用聊天示例中的 temperature。

不支持参考音频、改写/续写、独立歌词、纯器乐、音色、语速、时长或格式参数。曲风、情绪、乐器和无人声意图写入提示词；不保证上游一定遵循音乐风格要求。

生成只提交一次，不自动重新创建。供应商建议 600 秒超时；宿主任务整体期限与下载恢复机制继续生效。下载链接会过期，两首音乐须及时存入宿主资源库。少于两首不视为完整成功。

接口映射见 [docs/interface.md](docs/interface.md)。运行 `python build.py` 同步包内文档并生成可安装包。
