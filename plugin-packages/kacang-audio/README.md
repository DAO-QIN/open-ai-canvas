# 文本音乐生成

`yingce.plugin/v2` 声明式协议，沿用插件 ID `kacang-audio` 与协议 ID `kacang-suno`。升级现有插件即可，不需要重复安装。宿主管理鉴权、出站安全、任务审计与结果持久化，插件只声明请求和响应。

适配 [Suno v6 接口](https://console.prompt-hubs.com/docs/model/suno-v6)，也可用于采用相同接口合同的其他模型，不设模型名白名单。复用前需确认该服务支持聊天消息输入、`n=1`、`stream=false`，并在 `choices[0].message.content` 返回可下载的音频链接。不能仅凭名称判断兼容性。

选择协议后自动配置文本音乐、每次一个任务、非流式、3000 个 UTF-16 单元输入上限，以及默认歌曲／可选纯音乐。默认保存实际返回的全部音频，不假定固定两首。管理员可按已确认的模型合同调整输入上限、纯音乐支持和返回首数；返回首数为 0 表示随模型。价格、成本与启用状态独立保留。

用户只需描述想要的曲风、心情、乐器和演唱方式，选择歌曲或纯音乐。没有独立歌词、指定时长、参考音频、音色、语速和输出格式参数。

生成只提交一次，不自动重建；默认单次请求等待 600 秒，可按模型配置 1–3600 秒。任务执行额外预留三分钟保存结果；更长的管理员音频任务期限继续保留。短效结果链接会立即保存为站内资源，多首分别保存；下载恢复不会重新生成。返回空结果、非音频或下载失败不视为成功。

运行 `python build.py` 同步接口文档并生成标准 `.yingce-plugin` 包。详细映射见 [docs/interface.md](docs/interface.md)。
