# YuxiBox SD 视频

通过三个独立协议接入 YuxiBox 的 Seedance 2.0、Seedance 2.5 按秒及按次模型。选择协议后，管理端「能力与参数」自动填入官方支持的时长、比例、720P 分辨率和参考素材数量。

Base URL：`https://yuxibox.cn`。使用该站 default 或 seedance 分组的 API Key，密钥只由宿主渠道保存与使用，不进入插件包。

一手依据：[YuxiBox 模型广场](https://yuxibox.cn/pricing) 中对应模型的「API」标签页。完整请求、查询、结果下载与默认值见 [docs/interface.md](docs/interface.md)。
