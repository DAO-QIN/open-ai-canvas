# 968API SD 视频

通过五个专属协议接入 `sd-2.0`、`sd-c2`、`sd2.5`、`sd2.5-15`、`sdmini`。选择与上游模型一致的协议后，管理端自动填入对应能力和参数。

Base URL 为 `https://ap.968968968.xyz/v1`，使用该站的视频分组 API Key。创建、查询和临时结果转存由宿主执行，密钥不进入插件文件。

接口及参数依据：[968API 模型定价与参数](https://ap.968968968.xyz/videos#prices)、[968 官方画布](https://mf.968968968.xyz/)。官方画布视频请求代码是请求字段的一手依据，界面中的通用图片路径占位提示不适用于视频。

详细合同见 [docs/interface.md](docs/interface.md)。
